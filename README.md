# ERPSE Flow

Android-App für gerätegestütztes Ausdauertraining. Zentrale Funktion ist die
tatsächliche Steuerung kompatibler Trainingsgeräte (Wahoo-Rolle, MOXY);
Messdaten, Diagnostik und Auswertung unterstützen diese Funktion.

Grundlage: `docs/konzept/ERPSE_Flow_Gesamtkonzept_v1.0.md` (22. September 2026).

Nachweis realer Hardwarekompatibilität. Dieses Repository enthält bisher
